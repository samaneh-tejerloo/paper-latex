\subsection{Comparing the performance of loss functions and graph neural network architecture}

In this section, we compare the performance of the proposed loss functions, namely W-NOCD and HO-NOCD, with the original NOCD loss using two graph neural network architectures, GCN and GAT. The input features consist of binary GO features derived from the BP and MF subgraphs. A threshold of $0.3$ is used to extract functional modules for evaluating the performance of functional module identification under these settings. The experiments are conducted on three PPI datasets: Collins, Krogan-Core, and DIP.

Table~\ref{table:loss_arch_results} presents the results obtained on the Collins dataset. The results demonstrate the superiority of W-NOCD over both HO-NOCD and the original NOCD loss in terms of the F1 score. Furthermore, when comparing the two GNN architectures, GAT consistently outperforms GCN in terms of F1 score across all loss functions.

\subsection{Comparing the Activation Functions}

In this section, we investigate the effect of different activation functions on functional module identification using the GAT architecture with both binary and embedding-based features. We first evaluate the activation functions using binary GO features and then using GO embedding features.

For the binary features, the results show that ELU achieves the highest Precision across all datasets. However, ReLU generally provides the highest F1 score and Accuracy. The only exception is the Krogan-Core dataset, for which GELU achieves better performance than ReLU in terms of these metrics.

For the embedding features, the results are somewhat different for the Collins dataset. In this case, ELU achieves a higher F1 score, with improvements of 6\% and 9\% compared with GELU and ReLU, respectively. Furthermore, for Collins, ReLU achieves the highest Precision, whereas GELU provides the highest Accuracy. For the other datasets, ReLU generally outperforms the other two activation functions.

Overall, the results indicate that ReLU provides the most consistent performance across datasets and feature types, particularly in terms of F1 score and Accuracy. Therefore, ReLU is selected as the activation function for the subsequent experiments.

\subsection{Analyzing the JKNet Mechanism}

In this section, we investigate the effect of incorporating the JKNet mechanism into the proposed architecture. Three JKNet aggregation strategies are evaluated: MaxPooling, Concatenation, and LSTM Attention. The results show that the standard GAT architecture consistently outperforms the GAT models incorporating these JKNet mechanisms.

For the Collins dataset, although the differences in performance are relatively small, GAT achieves a higher F1 score than all three JKNet variants. This advantage is more pronounced on the Krogan-Core dataset, where GAT achieves a considerably higher F1 score than the models incorporating JKNet mechanisms. Overall, despite the motivation behind JKNet to combine representations from different layers of the graph neural network, the experimental results do not indicate a performance improvement from incorporating these mechanisms into the proposed architecture for functional module identification in PPI networks.
